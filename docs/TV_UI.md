# UI и управление пультом

Приложение должно полностью управляться D-pad: стрелки, OK (DPAD_CENTER/ENTER), Назад.

## Раскладка

- `isTvDevice()` (UiModeManager TELEVISION или `FEATURE_LEANBACK`) или ширина ≥ 640dp / ландшафт →
  `NavigationRail` слева, иначе нижняя `NavigationBar`.
- Назад на любом экране, кроме Home, возвращает на Home (`BackHandler` в `MainApp`).
- Каждый экран после открытия ставит фокус на главный элемент (через `FocusRequester` +
  `delay(150)`): Home — кнопка подключения, Servers — первый сервер или «Add Server», Apps — вкладка
  политики, Logs — «Copy».

## Правила

1. **Фокус-подсветка:** `Modifier.tvFocusVisual()` для готовых Material-компонентов; для своих
   кликабельных блоков — `Modifier.tvCardFocusable { }` (внутри: `tvFocusVisual` → `clickable`).
   Не добавляйте `focusable()` перед `clickable` — получится второй focus target, OK не сработает.
2. **Без вложенных focusable.** Кнопки внутри кликабельной карточки недостижимы стрелками.
   Делайте зону выбора и кнопки соседями в `Row` (см. `ServerItemCard`).
3. **Переключатели:** `SettingSwitchRow` — вся строка `toggleable`, сам `Switch` с
   `onCheckedChange = null`. Не делайте маленький отдельный Switch целью фокуса.
4. **Подписи у действий.** На ТВ используйте кнопки с текстом («Edit», «Delete»), а не только иконки.
5. **Основные действия — сверху или в потоке фокуса.** Плавающие кнопки (FAB) в углу плохо
   достижимы пультом.
6. **Текстовые поля — только `TvTextField`**, не `OutlinedTextField` напрямую. Compose открывает
   клавиатуру при любом получении фокуса полем, поэтому на ТВ она выскакивала просто при
   перемещении стрелками, а после закрытия кнопкой «Назад» открывалась снова (поле оставалось
   в фокусе). `TvTextField` на ТВ держит поле `readOnly`, пока по нему перемещаются: OK начинает
   ввод, действие IME (Next/Done), закрытие клавиатуры или уход фокуса заканчивают его. На
   телефоне это обычное поле. Задавайте `imeAction = Next/Done`. Ввод с пульта долгий —
   предлагайте готовые варианты (как пресеты DNS).
7. **Прокручиваемый не-фокусируемый контент** (журнал) — сам список `focusable()` +
   `onPreviewKeyEvent` для DPAD_UP/DOWN, возвращать `false` на краях, чтобы фокус мог уйти.
8. **Системные Activity могут отсутствовать на ТВ** (выбор документа, подтверждение тоннеля):
   ловите `ActivityNotFoundException` и предлагайте обходной путь (ввод ключа текстом, команда ADB
   `appops set <pkg> ACTIVATE_VPN allow`).
9. **Уведомления на ТВ не видны** — ошибки дублируются на экране (Home показывает последнюю
   ошибку журнала).
10. **Формы с вводом — на весь экран, не в диалоге** (`FullScreenEditor` в `ServersScreen`):
    окно диалога на ТВ меняет размер и центрируется заново при каждом изменении содержимого или
    клавиатуры, и форма «дёргается». Список под формой не рисуется, чтобы фокус не уходил в него;
    «Назад» = «Отмена» (`BackHandler`). `AlertDialog` — только для коротких подтверждений без полей
    ввода (удаление сервера, инструкции).

## Ручная проверка на ТВ

- Пройти все вкладки только стрелками; на каждом элементе видна рамка.
- Добавить, отредактировать, удалить сервер, выбрать активный, подключиться/отключиться — только OK.
- В форме сервера пройти все поля стрелками: клавиатура не должна появляться, пока не нажат OK;
  после «Назад» на клавиатуре она не открывается снова, форма не прыгает.
- Переключить каждую настройку, выбрать DNS-пресет, ввести свой DNS.
- Прокрутить журнал вверх/вниз и выйти из него стрелкой вверх.
